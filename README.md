⚙️ Installation & Usage

1️⃣ Clone the Repository
  1 - git clone https://github.com/Ranjeet0611/instagram-reels-analyser.git
  2 - cd instagram-reels-analyser

2️⃣ Install Dependencies
  1 - pip install -r requirements.txt

3️⃣ Run the Analyser
  1 - python main.py --url "https://www.instagram.com/reel/rO22Qa1kc8y/" \
               --compare_url "https://www.instagram.com/reel/yPtHAB1kes6/"
